# i77pass.com

Live Interstate 77 road conditions, closures, restrictions, and webcams from the North Carolina line to Hillsville, Virginia, over Fancy Gap, built on VDOT data via 511 Virginia and National Weather Service forecasts. A Bright Red Design pass network site, built in the i80pass master pattern from the network slim clone base.

## Stack

Next.js 16 App Router (standalone output), React 19, Tailwind CSS 4. Server side data layer in `lib/feeds.js` (the keyless VDOT 511 Virginia datasets: incidents and work zones, minor incidents, and message signs; see the project FEED-NOTES) and `lib/weather.js` (NWS forecasts). Camera inventory is a bundled snapshot in `lib/cameras.json`, generated by `scripts/build-cameras.mjs` from the live VDOT camera layer (22 cameras, mileposts 0.1 to 15.0, hot linked with credit to VDOT, never rehosted).

## Environment variables

No values live in this repo. Set at the host (Amplify forwards them via `amplify.yml`):

- `RESEND_API_KEY`: storm alert signups.
- `STORM_ALERTS_SEGMENT_ID`: dedicated Resend segment, once created; the subscribe route falls back to the network General segment until then.
- `NEXT_PUBLIC_GA_ID`: this site's own GA4 measurement ID.
- `NEXT_PUBLIC_ADSENSE_ID`: set to ca-pub-7809777915412999 at activation; the loader follows the sister pattern and stays inert until the ID is set.

The VDOT datasets are keyless; there is no agency key for this corridor.

## Develop

```bash
npm install --legacy-peer-deps
npm run dev
npm run build
```

## Scripts

- `scripts/build-cameras.mjs`: rebuild `lib/cameras.json` from the live VDOT 511 camera layer.
- `scripts/log-status.mjs`: append a status history entry to `data/status-log.jsonl` when a segment signature changes (scheduled hourly at launch; the public page renders the honest empty state until entries exist).
